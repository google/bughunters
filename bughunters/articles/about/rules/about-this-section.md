Welcome to the VRP rules section! Here, you’ll find an overview of the different
vulnerability reward programs Google maintains, as well as guidance on related
programs. See the below sections for an overview of the available programs,
their scope, and where to report issues or submit contributions. Happy bug
hunting!

If you have questions related to our handling of submitted security reports or
the general functionality of the
[bughunters.google.com](http://bughunters.google.com) site, see our
[FAQ page](/about/4925519884451840).

Tip: Not sure which program to report the issue you've discovered to? When in
doubt, report to the
[Google and Alphabet Vulnerability Reward Program (VRP)](/about/rules/6744710187712512/about-this-section#google-amp-friends).
